# THƯ MỤC KẾT QUẢ ĐỐI CHUẨN TPS-INBETWEEN FINETUNED v0.3

Nơi lưu trữ toàn bộ số liệu đo lường định lượng và báo cáo nghiệm thu của phiên bản **TPS-Inbetween Fine-tuned v0.3 (ASF-GR Engine)**:
- `tps_finetuned_v0.3_benchmark_report.md`: Báo cáo đối chuẩn nghiệm thu chính thức phiên bản v0.3 (Zero-Ghosting).
- `summary_metrics.json`: Tổng hợp so sánh đối đầu 3 bên (v0.3 vs v0.2 vs TPS Coarse).
- `val_508_metrics.csv`: Chi tiết điểm số từng sample trong tập Validation.
- `visual_samples_metrics.csv`: Chi tiết kết quả kiểm thử trên bộ mẫu thực tế `visual_samples` (Bamboo, TestImage1, TestImage2, ChayGo).
- `time_step_analysis.csv`: Phân tích hiệu năng theo từng mốc thời gian $t$.
